# 🌟 Student Portfolio - Modern Developer Portfolio

A stunning, responsive portfolio built with React that showcases my journey as a developer. Features dark mode, GitHub integration, and interactive project showcases.

![Portfolio Demo](https://via.placeholder.com/800x400?text=Portfolio+Demonstration)

## ✨ Features

- 🌙 **Dark/Light Mode** - Smooth theme switching with system preference detection
- 📱 **Fully Responsive** - Perfect on all devices from mobile to 4K displays
- 🎨 **Beautiful Design** - Modern sky blue color scheme with smooth animations
- 📊 **GitHub Integration** - Live stats fetched from GitHub API
- 🎯 **Skills Carousel** - Interactive carousel showcasing technical skills
- 📁 **Project Showcase** - Detailed project modals with tech stack and links
- ⚡ **Performance Optimized** - Fast loading and smooth transitions
- ♿ **Accessibility Ready** - Semantic HTML and ARIA labels

## 🛠️ Tech Stack

- **Frontend**: React 18 + Vite
- **Styling**: Pure CSS with CSS Variables
- **API**: GitHub REST API v3
- **Icons**: Emoji + Unicode (no external libraries)
- **Deployment**: Vercel / Netlify Ready
